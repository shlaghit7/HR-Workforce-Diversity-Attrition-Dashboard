# HR Workforce Diversity & Attrition Dashboard

## Project Overview

An interactive Tableau dashboard designed to analyze workforce diversity, employee attrition, satisfaction trends, and HR performance metrics.

## Tools Used

- Tableau
- Excel
- CSV
- HR Analytics
- Data Visualization

## Key KPIs

- Total Employees
- Attrition Rate %
- Diversity Ratio %
- Average Salary
- Satisfaction Score
- Promotion Rate
- High Risk Employees

## Dashboard Features

- KPI Cards
- Attrition Analysis
- Diversity Analysis
- Heatmaps
- Scatter Plot
- Interactive Filters

This dashboard helps HR teams improve workforce planning, employee retention, and diversity initiatives.
